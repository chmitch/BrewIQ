Microsoft architecture icons

The diagram uses Azure, Foundry and Power BI symbols from the Azure and
Power Platform libraries bundled with draw.io. Microsoft permits these icons
in architectural diagrams and documentation; Microsoft reserves other rights.

https://learn.microsoft.com/en-us/azure/architecture/icons/
https://learn.microsoft.com/en-us/power-platform/guidance/icons
https://github.com/jgraph/drawio/tree/dev/src/main/webapp/img/lib/azure2

Microsoft Fabric icons

Official Fabric product, notebook, eventstream, eventhouse and lakehouse SVGs
are embedded unmodified in brewiq-overview.drawio. The selected files come
from the v6.1.0 package in Microsoft's published Icons.zip.

https://learn.microsoft.com/en-us/fabric/fundamentals/icons
https://github.com/microsoft/fabric-samples/blob/main/docs-samples/Icons.zip
